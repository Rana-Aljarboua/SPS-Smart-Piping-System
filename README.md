# SPS Control Room — web demo

`index.html` is the self-contained SPS control-room interface (3D pipeline
network, sensor monitoring, analytics, alerts, leak localization and a demo
simulation). It is published with GitHub Pages from this `docs/` folder.

All readings are synthetic and produced by the built-in demo data engine.
No physical sensors and no SPS backend are connected.

Libraries load from public CDNs (Three.js r128, Chart.js 4.4.1, Google Fonts),
so viewers need an internet connection.
